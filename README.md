📦 Gestor Inteligente de Pedidos, Ventas y Stock para Emprendedores | Innova Lab | Equipo 24

🚀 Descripción del ProyectoEste proyecto es una plataforma web de gestión operativa orientada a pequeños emprendimientos. Su objetivo principal es centralizar y ordenar el ciclo completo de los pedidos (desde el ingreso hasta la entrega y cobro), manteniendo un control actualizado del stock en tiempo real sin caer en la complejidad de un ERP tradicional.   

🎯 Problemática que ResuelveMuchos emprendedores gestionan sus ventas de forma informal a través de notas o chats (especialmente WhatsApp). Esto genera:   Pedidos dispersos sin un registro centralizado.   Dificultad para saber el estado de cada pedido (recibido, en preparación, entregado, etc.).   Falta de control sobre el stock actual (incluyendo productos con variantes de talle, color, etc.).   Errores en cobros, entregas o reposiciones.   

💡 Solución PropuestaUna herramienta intuitiva que consolida la operación diaria en un único panel con automatizaciones clave:   Centralización de pedidos: Carga manual y recepción automática mediante integración con la API oficial de WhatsApp.   Catálogo & Variantes: Control de productos con sus respectivos precios, stock disponible, stock mínimo y variantes (talle, color, sabor, etc.).   Gestión de Stock Automática: Descuento/reserva de unidades al confirmar un pedido y devolución automática en caso de cancelación.   Seguimiento & Cobros: Flujo de estados claro (Recibido ➔ En preparación ➔ Listo ➔ Entregado) y control de cobros (Pagado / Pendiente).   Alertas & Dashboard: Avisos de bajo stock e indicadores de ventas del período, productos más vendidos y pagos pendientes.   

🛠️ Stack Tecnológico SugeridoFrontend: React / Next.js + Tailwind CSS   Backend: Node.js + Express / NestJS   Base de Datos: PostgreSQL / Supabase   Integraciones: WhatsApp Business Platform API (Webhooks)
