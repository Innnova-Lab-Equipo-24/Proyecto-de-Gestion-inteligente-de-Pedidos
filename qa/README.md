# QA

Área de aseguramiento de calidad del proyecto **Gestor de Pedidos**.

## Responsabilidades

- Pruebas (unitarias, integración, E2E).
- Revisión de PRs y aprobación para pase a `Done`.
- Criterios de aceptación y reporte de bugs.

## Propietarios

- `@Ryojix3`

## Flujo

Las revisiones de `@Ryojix3` sobre un PR mueven los issues vinculados a `Done`
(vía `auto-move-issues.yml`). Las revisiones que piden cambios devuelven el issue
a `In Progress`.
